# SaveMod — JavaScript-бот (grammy)

Telegram Business-бот: сохраняет переписку, замечает удалённые и изменённые
сообщения, выгружает историю в автономный HTML-архив, импортирует выгрузки
Telegram Desktop.

Это **основная версия бота** — та самая, с полным дизайном и кастомными
эмодзи.

## Установка

```bash
cd js
npm install
cp ../.env.example .env        # вписать BOT_TOKEN и ADMIN_IDS
npm start
```

Нужен Node.js **22.5+** (используется встроенный `node:sqlite`) и Python 3
только для тестов.

`.env` ищется в двух местах: `js/.env` (рекомендуется) и корень проекта.
Раньше читался только первый, и файл, положенный в корень по инструкции,
молча игнорировался.

## Зависимости

| Пакет | Зачем |
|-------|-------|
| `grammy` | клиент Bot API |
| `@grammyjs/runner` | параллельная обработка обновлений |

SQLite берётся из самого Node (`node:sqlite`) — нативных сборок нет,
`better-sqlite3` и `node-gyp` больше не нужны. Это важно: раньше установка
падала на сборке C++-модуля.

## Дизайн меню

Главное меню — исходная раскладка:

```
Настройки | Подключить бота
Пригласи друга
Подписка
Админ-панель            ← только админу
```

Все кнопки получают `style` (`primary` / `success` / `danger`) и
`icon_custom_emoji_id` — кастомные эмодзи и в тексте, и в иконках кнопок.

## Кастомные эмодзи

В текстах — `<tg-emoji emoji-id="…">💎</tg-emoji>` с `parse_mode=HTML`,
в кнопках — поле `icon_custom_emoji_id`. Идентификаторы взяты из исходного
проекта (`menuKeys.js → EMOJI`), поэтому картинки те же.

Право на кастомные эмодзи есть у бота, если у владельца аккаунта
**Telegram Premium** (это ваш случай) либо у бота юзернейм с Fragment.
Если Telegram всё же откажет (`DOCUMENT_INVALID` / `BUTTON_ICON_INVALID`),
бот один раз перестроится и дальше шлёт меню с обычными эмодзи — кнопки и
экраны продолжают работать, пользователь ничего не теряет.

## Баннеры

Файлы лежат в `../assets/`, имена — как в конфиге:

```
main         → assets/mainmenu.jpg
settings     → assets/settings.jpg
subscription → assets/subscription.jpg
admin        → assets/adminmenu.jpg
```

Перед отправкой проверяется сигнатура файла (JPEG/PNG/GIF/WEBP). Нет файла
или это не картинка — меню уходит текстом. Раньше путь вёл в несуществующую
`image/`, и баннеры не отправлялись вообще, хотя файлы были на месте.

## Команды

| Команда | Что делает |
|---------|------------|
| `/start` | главное меню, регистрация, реферальный бонус |
| `/export` | выбрать чат и создать HTML-архив |
| `/archive` | импорт `result.json` / ZIP из Telegram Desktop |
| `/admin` | админ-панель |

Управление перехватом прямо в Business-чате: `.nah`, `.love`, `.bypass`,
`.mute`, `.unmute`. Точка или запятая от собеседника — перехват сгорающих
медиа.

## Тесты

```bash
cd js
npm test
```

- `test/menu.test.js` — клавиатуры и тексты без сети (22 проверки);
- `test/flow.test.js` — сквозной прогон настоящего бота против фейкового
  Telegram API (14 проверок).

Фейковый сервер (`test/fake_api.py`) умеет имитировать отказ на кастомные
эмодзи, поэтому боевой сценарий `DOCUMENT_INVALID` проверяется по-настоящему.

## Что было починено при восстановлении

Версия в репозитории не запускалась и не работала как задумано:

| Проблема | Последствие | Исправление |
|----------|-------------|-------------|
| `require('./business')` при файле `bussines.js` | бот падал на старте | правильное имя модуля |
| `require('better-sqlite3')` без `package.json` | установка невозможна, нативная сборка | `package.json` + встроенный `node:sqlite` |
| `InlineKeyboard.text({ callback_data })` | grammy подменял данные текстом — **все кнопки мертвы** | `callback_data` вторым аргументом |
| нет `saveMessage` / `saveEditedMessage` / `markMessagesDeleted` | переписка молча не сохранялась, экспорт всегда пустой | методы добавлены |
| баннеры искались в `image/` | меню всегда текстом | путь в `../assets` |
| `API_SERVER` игнорировался | нельзя проверить локально | адрес Bot API настраивается |
| кнопка «Поделиться ссылкой» без обработчика | мёртвая кнопка | обработчик `share_ref` |
| отказ на эмодзи в фото не повторялся | меню могло не дойти | `sendPhoto` в списке повторов + кэш отказа |
