# Бот перехвата удалённых и изменённых сообщений

Telegram-бот для работы с **Telegram Business**: сохраняет переписку,
уведомляет об удалённых и изменённых сообщениях, экспортирует чаты в HTML
и импортирует историю из Telegram Desktop.

Переписан на **aiogram 3** (Python).

## Установка

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
# впишите BOT_TOKEN и ADMIN_IDS

python run.py
```

Нужен Python 3.10+ (рекомендуется 3.11–3.13).

## Что где лежит

```
run.py                 запуск
bot/
  config.py            токен, админы, цены, лимиты, .env
  database.py          SQLite + шифрование (совместимо со старой базой)
  keyboards.py         все inline-клавиатуры
  menu.py              тексты меню и отправка баннеров
  archive.py           экспорт в HTML, импорт Telegram Desktop
  business.py          Telegram Business события
  handlers/
    user.py            меню, тарифы, приглашения, экспорт, импорт
    admin.py           админ-панель, бан, рассылка
    payments.py        оплата звёздами, inline-режим
    messages.py        перехват «сгорающих» медиа
assets/banner_*.jpg    картинки меню
tests/                 офлайн-тесты (фейковый Bot API)
```

## Баннеры и ошибка DOCUMENT_INVALID

Раньше бот всегда вызывал `sendPhoto()` с путём к баннеру. Если файла не
было (папка `image/` отсутствовала в репозитории), Telegram отвечал
`400: DOCUMENT_INVALID` и меню не отправлялось вообще.

Теперь:

1. перед отправкой проверяется, что файл существует и является настоящим
   JPEG/PNG (проверка сигнатуры + Pillow);
2. если проверка не прошла — меню отправляется текстом, без картинки;
3. если Telegram всё равно отклонил фото — меню тоже уходит текстом;
4. после первой успешной отправки кэшируется `file_id`, картинка больше
   не загружается.

Свои картинки можно подставить через `.env` (`BANNER_MAIN` и т. д.),
ничего не меняя в коде.

## Совместимость с прежней базой

Схема таблиц и формат шифрования (`AES-256-GCM`, префикс `enc:v1:`)
полностью совпадают с Node-версией: существующий `bot_database.sqlite`
подхватывается без миграции, старые сообщения расшифровываются.

## Тесты

```bash
python tests/test_flow.py       # 31 клик по кнопкам через реальный aiogram
python tests/test_keyboards.py  # все клавиатуры
python tests/test_banner.py     # баннеры и DOCUMENT_INVALID
python tests/test_archive.py    # экспорт/импорт, zip-slip, XSS
```

Тесты работают офлайн: `tests/fake_telegram.py` поднимает локальный сервер,
имитирующий Bot API, поэтому проверяется настоящий aiogram, а не заглушки.
