# SaveMod — бот для Telegram Business

Telegram-бот для работы с **Telegram Business**: сохраняет переписку,
уведомляет об удалённых и изменённых сообщениях, экспортирует чаты в
автономный HTML и импортирует историю из Telegram Desktop.

**Основная версия — на JavaScript** (Node.js + grammy), в каталоге
[`js/`](js/README.md). Полный дизайн меню и кастомные эмодзи на месте.

```bash
cd js
npm install
cp ../.env.example ../.env    # вписать BOT_TOKEN и ADMIN_IDS
npm start
```

Подробности — в [`js/README.md`](js/README.md).

## Что умеет

- **Меню** — исходная раскладка: `Настройки` | `Подключить бота`,
  `Пригласи друга`, `Подписка`; у админа — `Админ-панель`.
  Все кнопки со стилями и кастомными эмодзи.
- **Telegram Business** — сохранение переписки, перехват удалённых и
  изменённых сообщений, сгорающие медиа по точке `.` или запятой `,`.
- **Оплата** звёздами: 7 дней — 25 ⭐️, 30 — 75 ⭐️, 90 — 150 ⭐️,
  Премиум — 300 ⭐️.
- **Рефералы**: приглашённый +3 дня, пригласивший +7 дней.
- **Экспорт** в самодостаточный HTML (стили внутри, XSS экранирован) и
  **импорт** `result.json` / ZIP из Telegram Desktop (защита от zip-slip).
- **Админ-панель**: статистика, подписки, премиум, бан, рассылка.
- **Шифрование** текстов: AES-256-GCM, префикс `enc:v1:`.

## Баннеры

Имена файлов ровно такие, как в конфиге:

```
main         → assets/mainmenu.jpg
settings     → assets/settings.jpg
subscription → assets/subscription.jpg
admin        → assets/adminmenu.jpg
```

Перед отправкой проверяется сигнатура файла. Нет файла или это не картинка —
меню уходит текстом, бот не падает.

## Кастомные эмодзи

Нужен Telegram Premium у владельца аккаунта (есть) либо юзернейм бота,
купленный на Fragment. Если Telegram всё же откажет с `DOCUMENT_INVALID`,
бот автоматически переходит на обычные эмодзи — меню продолжает работать,
пользователь ничего не теряет.
