# SaveMod — бот для Telegram Business (Rust)

Telegram-бот для работы с **Telegram Business**: сохраняет переписку,
уведомляет об удалённых и изменённых сообщениях, экспортирует чаты в
автономный HTML и импортирует историю из Telegram Desktop.

**Актуальная версия — на Rust**, в каталоге [`rust/`](rust/README.md).
Собирается на голом `std` + системном `libcurl`: ни одного внешнего крейта,
`cargo build` не ходит в интернет.

```bash
cd rust
./build.sh
cp ../.env.example ../.env    # вписать BOT_TOKEN и ADMIN_IDS
./run.sh
```

Подробности — в [`rust/README.md`](rust/README.md).

## Главное

- **Меню** — `Тарифы` / `Пригласить друга`, затем `Подключение`, затем
  `Настройки`; у админа — `Админ-панель`. Кнопки **«Создать бота» больше нет**.
- **Telegram Business** — сохранение переписки, перехват удалённых и
  изменённых сообщений, сгорающие медиа по точке `.` или запятой `,`.
  Управление из чата: `.nah`, `.love`, `.bypass`, `.mute`, `.unmute`.
- **Оплата** звёздами: 7 дней — 25 ⭐, 30 — 75 ⭐, 90 — 150 ⭐, Премиум — 300 ⭐.
- **Рефералы**: приглашённый +3 дня, пригласивший +7 дней.
- **Экспорт** в самодостаточный HTML (стили внутри, XSS экранирован) и
  **импорт** `result.json` / ZIP из Telegram Desktop (свой inflate, защита от zip-slip).
- **Админ-панель**: статистика, подписки, премиум, бан, рассылка.
- **Шифрование** текстов: AES-256-GCM, префикс `enc:v1:` — совместим с прежними версиями.

## Баннеры

Имена файлов ровно такие, как в конфиге:

```
main         → assets/mainmenu.jpg
settings     → assets/settings.jpg
subscription → assets/subscription.jpg
admin        → assets/adminmenu.jpg
```

Файл проверяется по сигнатуре до отправки. Нет файла или это не картинка —
меню уходит текстом. Telegram отклонил фото — меню всё равно уходит.

## Исправленные боевые проблемы

| Проблема | Что было | Что сделано |
|----------|----------|-------------|
| `DOCUMENT_INVALID` | бот падал, пользователь ничего не получал | эмодзи отключаются на процесс, меню переотправляется без них |
| «there is no text in the message to edit» | кнопка под фото-меню не работала | бот ловит отказ и отправляет новое сообщение |
| Кастомные эмодзи требуют прав | нет Premium у владельца / юзернейма с Fragment | плавная деградация до обычных эмодзи, `CUSTOM_EMOJI=off` для принудительного отключения |
| Кнопки «мертвеют» | `callback_data` подменялся подписью | данные всегда отдельным полем, проверяется длина 1…64 |

## Тесты

```bash
cd rust && ./test.sh
```

98 тестов: 86 юнит, 2 в точке входа, 10 интеграционных на фейковом сервере
Telegram. Фейк умеет воспроизводить оба боевых отказа, поэтому исправления
проверены по-настоящему, а не «на глаз».
